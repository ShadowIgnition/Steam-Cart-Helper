# Steam Cart Helper

Search Steam and add a game's main store package to your cart from the extension popup.

> Unofficial tool. Steam Cart Helper is not affiliated with Valve or Steam.

## Install

1. Download and extract the project ZIP.
2. In Chrome, open `chrome://extensions`.
3. Turn on **Developer mode** (Must remain on in-order to use extension).
4. Select **Load unpacked** and choose the extracted folder containing `manifest.json`.
5. Pin **Steam Cart Helper** from Chrome's Extensions menu if you want quick access.

## Use

1. Open the Steam Store in Chrome and sign in if needed.
2. Open Steam Cart Helper from Chrome's Extensions menu.
3. Search for a game by title. You can also enter a Steam App ID directly.
4. Choose **Add to cart** beside the game you want.

## Notes

- Add-to-cart works only while the active tab is the Steam Store. Otherwise, the extension offers to open it.
- Results without a main Steam store package are not shown.
- Search terms go directly to Steam. The extension has no analytics and does not store searches.

## Updating

Replace the extension files with the latest version, then select **Reload** from `chrome://extensions`.
